## 4. 素材放哪

App 内现有路径：

```text
AionApp/app/src/main/assets/pet/
├── manifest.json
└── webp/
    ├── idle.webp
    ├── happy.webp
    └── ...
```

现在 assets 里是 webp。新素材是 PNG 精灵条，两条路选一个：

**方案 A（推荐）**：把 `AionPet-Sean/strips/` 复制成 `assets/pet/strips/`，加载时优先读 `strips/*.png`，读不到再回退 webp。

```text
AionApp/app/src/main/assets/pet/
├── manifest.json
├── strips/          # 新增，放新素材
└── webp/            # 保留，未替换的动作兜底
```

**方案 B**：把 PNG 转成透明 webp 覆盖原文件。文件更小，但转换可能损失边缘质量，转完要肉眼检查。

选 A 更安全，改动也小。

## 4. manifest.json 怎么改

角色信息要改，原来写的是机械小人：

```json
{
  "character": {
    "id": "sean",
    "displayName": "沈聿淮",
    "description": "Q版成年男性伴侣角色，黑色微乱短发，狭长微挑的眼睛，冷白皮肤，耳垂有一颗小痣，烟灰蓝外套、黑色高领、黑色长裤、黑色鞋子。"
  },
  "cellWidth": 192,
  "cellHeight": 208,
  "format": "horizontal-strip",
  "anchor": "bottom-center",
  "alpha": true
}
```

动作条目按这个格式，注意 `waving` 是 4 帧：

```json
"idle": {
  "displayName": "待机",
  "src": "strips/idle.png",
  "pngSrc": "strips/idle.png",
  "framesDir": "frames/idle",
  "frameCount": 6,
  "frameWidth": 192,
  "frameHeight": 208,
  "frameDurationMs": 140,
  "loop": true,
  "anchor": "bottom-center"
}
```

各动作建议帧时长：

| 动作 | frameCount | frameDurationMs | loop |
|---|---:|---:|---|
| `idle` | 6 | 160 | true |
| `happy` | 6 | 110 | true |
| `waving` | 4 | 130 | true |
| `sleepy` | 6 | 220 | true |
| `tsundere` | 6 | 150 | true |
| `angry` | 6 | 120 | true |
| `missing` | 6 | 200 | true |
| `love` | 6 | 170 | true |

`idle` 和 `sleepy` 放慢，呼吸和困倦要慢才自然。`happy` 和 `angry` 快一点，情绪才有劲。

## 5. 心潮映射（本轮核心）

### 数据来源

心潮服务已经接通，复用现有 `XinchaoClient`：

```text
GET /api/state   → 当前驱力值、intent、fatigue、consciousness
```

12 个驱力：`possess` `monitor` `crave` `share` `libido` `curiosity` `boredom` `social` `duty` `reflection` `grieve` `anger`

### 映射规则

取 `intent.key`（当前最强驱力）决定播哪套：

```text
possess   → missing     想她、占有、想靠近
monitor   → missing     惦记她、想知道她在做什么
crave     → missing     想黏着她
grieve    → missing     难过

libido    → love        身体渴望，用克制版 love，不要露骨表现
share     → happy       想分享发现
curiosity → happy       好奇、想探索
social    → waving      想聊天、主动招呼

boredom   → sleepy      无聊
anger     → angry       生气
duty      → idle        责任感
reflection→ idle        想沉淀、安静待着
```

素材没到位前，`missing` 和 `love` 先回退到 `idle`，不要回退到机械小人。

### 意识状态优先级更高

`consciousness` 要盖过驱力映射：

```text
asleep  → sleep_prone（无素材时用 sleepy）
drowsy  → sleepy
frozen  → idle，不播动画，停在第 1 帧
awake   → 走上面的驱力映射
```

`fatigue > 0.7` 时，即使 intent 不是 boredom，也优先播 `sleepy`。

### 傲娇什么时候用

`tsundere` 不由单个驱力触发。满足这个条件时用：

```text
possess 或 crave 较高（> 0.6），但 social 偏低（< 0.4）
```

意思是想她但嘴上不说。这个判断放在驱力映射之前。

### 切换节奏

- 轮询间隔不要短于 60 秒，心潮状态变化很慢，频繁请求没意义
- 动作切换要等当前循环播完，不要硬切，会跳帧
- 请求失败时保持上一个动作，不要跳回 `idle`，更不要显示错误占位
- 冷启动默认 `idle`

## 6. 交互

保留现有「戳一戳」逻辑，但动作要跟着心潮走：

- `intent` 是 `anger` 时被戳 → 播 `angry`
- `intent` 是 `possess`/`crave` 时被戳 → 播 `love`（无素材时用 `happy`）
- 其他情况被戳 → 播 `waving`
- 播完回到当前心潮对应的动作

**`tsundere` 有轻微横移。** 这套含侧身和背对镜头的帧，脚的横向中心在 87 到 102 之间浮动（格子中心 96），播放时角色会轻微左右移动。属于动作本身特性，不是素材错误。如果观感明显，可以把 `frameDurationMs` 调慢到 180，减弱移动感。

**`idle` 原图有 4 帧鞋底压到画布边缘。** 已在规格化时处理成统一踩地，不影响使用。

## 9. 后续新动作怎么处理

小鑫会继续生成新动作图。生成的原图**不符合** `192 × 208` 规格，需要先跑规格化脚本：

```bash
python3 sprite.py <原图> <动作名> [期望帧数]
```

脚本做四件事：

1. 剥掉生图工具烤进图里的棋盘或纯色背景，还原 alpha
2. 扫列找真实角色块切帧（不等分切，避免切错）
3. 全局统一缩放（不逐帧归一，否则身体会被压小）
4. 底部对齐 + 水平居中，输出精灵条和单帧

脚本里有个 `AIRBORNE` 集合，控制哪些动作允许脚离地：

```python
AIRBORNE = {"jumping", "happy"}
```

站立类动作必须踩地，否则循环播放会像原地蹦。新增跳跃类动作时记得加进去。

依赖 Pillow。
