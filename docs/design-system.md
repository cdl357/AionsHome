# 设计系统 — 安静、亲密、清楚、耐看

> 像两个人的小家，不像一个软件，也不像一个玩具。

## 1. 关键词

安静 ｜ 亲密 ｜ 清楚 ｜ 耐看 ｜ 移动端优先

## 2. 颜色

单一变量源：`aion-chat/static/mobile/theme.css`（新页面专用；旧页面保持原样作回退）。

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#0b111f` | 深夜蓝，页面底色 |
| `--surface` | `#141d31` | 雾蓝，卡片/面板 |
| `--surface-2` | `#1b2740` | 雾蓝（浮层/悬停层） |
| `--border` | `rgba(151,166,199,.16)` | 分隔线、描边 |
| `--text` | `#f1ede2` | 暖白，主文字 |
| `--text-2` | `#aab6c9` | 雾蓝灰，次级文字 |
| `--text-3` | `#77839b` | 弱化文字/占位 |
| `--accent` | `#d9b877` | 淡金，主操作/强调 |
| `--accent-soft` | `rgba(217,184,119,.14)` | 淡金底（选中态、状态点） |
| `--lilac` | `#9d92b8` | 灰紫，少量辅助（标签/梦境） |
| `--danger` | `#d98a8a` | 失败/错误 |
| `--ok` | `#8fbf9a` | 连接正常 |

规则：

- 禁止：橙色主色、橘子元素、原项目暖橙壁纸作主视觉、高饱和霓虹、大面积花哨渐变、幼稚卡通风
- 页面之间共用同一套变量，不允许各页另起一套
- 强调色（淡金）用量克制：主按钮、当前态、状态点；正文永远是暖白/雾蓝灰

## 3. 视觉锚点

黑猫 ｜ 白猫 ｜ 月牙 ｜ 少量星点 ｜ 柔和纸张/水彩质感

- 正式插画就位前：以上锚点只存在于文案与结构预留中，不做任何替代图形（无占位图、无渐变插画、无 emoji 图形）
- 预留视觉区：首页 `.home-visual` 一个独立区块，插画将来只替换这一个区域，加入/移除都不改变布局（高度固定、不依赖图片尺寸）
- 图标：功能图标暂用文字或简单线性图标；正式猫耳/猫爪/尾巴/月牙图标等视觉方案稳定后统一替换

## 4. 字体

- 系统无衬线栈：`system-ui, -apple-system, "PingFang SC", "HarmonyOS Sans SC", "MiSans", "Noto Sans CJK SC", "Microsoft YaHei UI", sans-serif`
- 不用手写字体承载 UI 文本；中文小屏可读性优先
- 字号层级：页面标题 20/600；区块标题 13/600（letter-spacing .05em）；正文 15/400；辅助 12-13/400
- 行高：正文 ≥1.6

## 5. 间距与形状

- 间距基准 4px：常用 8/12/16/20/24
- 页面水平留白 20px；内容最大宽度 480px 居中
- 圆角小而统一：卡片 16px、按钮/输入框 12px、胶囊 999px；禁止卡片套卡片
- 阴影克制：一层柔和投影足够（`0 8px 24px rgba(0,0,0,.18)`）
- 安全区：`env(safe-area-inset-*)` 全量适配；底部导航高度含 `safe-area-inset-bottom`

## 6. 组件基线

统一使用一套：按钮（主=淡金底深字，次=雾蓝描边）、输入框、消息气泡、列表条目、状态提示、错误与空状态、底部导航（5 项，图标+文字，当前态淡金）、底部抽屉（「更多」）。

- 重要操作：图标 + 文字（当前阶段文字为主）
- 状态点语义：`--ok` 正常 ｜ `--accent-soft` 未登录/待处理 ｜ `--danger` 失败
- 空状态：一句轻的话 + 可选下一步动作；不放插画
- 加载：文本级「正在…」；不做大型骨架屏动画
- 移动端：`viewport-fit=cover`；软键盘用 `visualViewport` 兜底；无横向溢出；点按目标 ≥44px

## 7. 素材约束（当前阶段）

不生成、不下载、不引入任何图片（PNG/JPG/WEBP/SVG）；不用原 AionsHome 橙色背景、橙色图标、原头像作最终视觉。首页验收：无图片可正常显示、无 broken image、不依赖橙色壁纸、结构不因插画增删变形。
