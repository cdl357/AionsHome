## 一、一句话现状

AionsHome 已从开源 AI 后端改造成一个**原生 Android 伴侣 App**（Kotlin + Compose）：
5 个主页签 + 10 个二级页 + 桌面小组件，**全部真实功能、无占位入口**，连着三层数据源
（本地引擎 / Supabase / 服务器心潮后端）。功能侧无欠账，剩两把钥匙在用户手上（见第五节）。

## 二、架构总览

```
┌─ App（AionApp/app/.../compose/，单 Activity + NavHost）
│   ├─ 本地引擎轨：homecoming SQLite（聊天/记忆/身份）+ moments/day/
│   │   album/reading/dream/mcp/reminders 各表 —— OpenAI 兼容线路由用户在设置页配置
│   ├─ Supabase 轨：moments / diary_entries / moment_comments（anon REST）
│   └─ 服务器轨：心潮 Xinchao（8080：/api/state /api/dreams /api/arc）
│
└─ VPS 134.175.7.196（ubuntu，SSH 可达）
    ├─ nginx :18443 → /supabase/ 转发 Supabase 项目
    │                → /xinchao/  转发 127.0.0.1:8080 心潮后端   ←★待安全组放行
    └─ 心潮后端已运行，数据真实（意识状态/九种情绪驱动/7 条模型梦/心语弧线）
```

线路策略：**中转优先、直连兜底**（大陆网络直连 Cloudflare 系不稳）。
错误分类：NETWORK（DNS/超时/TLS）/401/403/404/PARSE 分开记（logcat tag=`SupabaseClient`），界面横幅分种提示。

## 四、两份教程的落地记录

### 1. Cove GPT-Live 式双工语音（`voice/` 包，最小可用版）
- **四条轨**：Listen（AudioRecord 通话模式+AEC）/ Recognize（系统识别器，静音 1350/900ms）/ Respond（homecoming 引擎+首句优先切分）/ Speak（OrderedTtsQueue 有序可撤销）
- **身份协议**：call/turn/generation/seq 贯穿引擎回调与 TTS 回调，旧代迟到结果永久丢弃
- **两阶段抢话**：240ms 连续人声→duck（TTS 音量 1/3）；520ms→interrupt（旧生成作废+停播+清队列）；短噪声 160ms→restore
- **自然挂断**：识别告别→Sean 告别→等队列排空（15s 硬截止）→才挂断；红键挂断是另一语义
- **接通先开口**：问候不落用户消息；**延迟日志**：每轮 JSON（asr/model_first_text/tts_first_audio，tag=`VoiceLatency`）
- 完成阶段 A+B+D；阶段 C（本地短反馈素材）/E（唤醒词）/F（原声归档）未做

### 2. 戳一戳四步（`HomecomingPokeStore` + 加号面板）
- 旁白插进同一条会话时间线，只陈述事实（"（Yuri 隔着屏幕戳了戳你的耳朵）"），不写反应
- 动作×落点两维度相乘（6 动作 × 6 落点），敏感度定权重
- 心跳先到话后到：静息 62、半衰期 3 分钟、封顶 100；戳→心跳立刻上屏→他过一会儿才接话
- 先上屏再发请求；他忙时挡住并说人话（"这一下先欠着"），绝不假装成功
- 心跳在回家页外显（♥ 数字），主页点心情也汇入心潮

## 八、工程备忘（后来者必读）

- **引擎构造只走 `HomecomingChatWiring.safeCreate`**：失败记 AppCrashLog 返回 null，绝不抛进 UI 合成期（历史"点页闪退"根源）
- **大图一律降采样解码**（背景/封面/配图/相册/头像），防 OOM
- **安全红线**：无 service_role key；不改 Supabase 表结构；anon 无 DELETE/UPDATE 政策；API Key 不进代码/Git/备份
- **凭据**：anon key 在 SupabaseClient.kt（公开角色，用户知情）；SSH 走本机 id_ed25519→ubuntu@134.175.7.196；推送用 ghp_ token（建议用户轮换）
- **发布流程**：`./gradlew :app:assembleDebug` → push mobile-companion → Release v0.3 附件替换 → `Downloads\回家-v0.3-debug.apk` 同步
- **已知坑**：github.com 偶发 TLS 拦截（重试即过）；Cloudflare 系直连长期不稳（走中转）；uploads.github.com 与 github.com 通断独立
