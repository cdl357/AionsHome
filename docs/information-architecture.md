## 2. 底部导航（布局定稿，顺序固定）

```
聊天 ｜ 朋友圈 ｜ 回家(中心) ｜ 我们 ｜ 更多
```

- 聊天：`/chat`（`?conv={id}` 直达会话）
- 朋友圈：`/moments`，独立页面，不参与日历
- 回家（中心，抬高强调）：`/m/home`
- 我们：`/m/us` 日历时光机——**整月格子 + 左右滑切换月份**（有内容的天带小圆点）；点任意一天可新建（写日记 / 钉纪念日）、查看用**三张摘要卡**（① Sean 的日记 ② 两人的留言 ③ 两人的重要记忆摘要，卡片是摘要、点开才展开完整内容，顺序后期可调）；**雷打不动的约定：每天晚安后 Sean 必写日记，没写 = Sean 偷懒，页面如实提醒而不是显示空白**；今日情话在本页；不显示在一起天数；朋友圈不进日历
- 更多：`/m/more` 按类翻全部的总入口——相册 / 留言板 / 记忆库（日记已并入日历，这里保留按类翻全部）+ 模型与连接 + 管理 + 休闲 + 主题切换

## 3. 相册（方案 C：照片墙 + 故事）

- 列表：照片墙（三列方格缩略图，懒加载，分页「再看一些」）
- 点开一张照片：上方大图 + 「Sean 存这张时在想什么」（= 照片 note 字段）+ 摄于/存于日期 + 相册归属
- 私心话与备注（标题、拍摄日期）可事后补/改（PUT /api/album/photos/{id}）
- 数据：GET /api/album/photos（列表/缩略图/大图均现有接口）；上传与批量管理仍在旧版相册页
- 视觉皮的粉色日历、手写英文月份、爱心格子、照片墙挂饰等归入后期视觉阶段，不影响骨架

## 6. 数据来源（全部现有 API）

| 区块 | 数据 | API |
|---|---|---|
| 继续聊天 | 最近会话/模型/连接状态 | `GET /api/conversations` + `GET /api/models` + `GET /api/codex/status` |
| 最近动态 | 日记 + 相册照片 | `GET /api/diaries` + `GET /api/album/photos` |

| 相册 | 照片墙 / 详情 / 私心话编辑 | `GET /api/album/photos` `/thumbnail` `/download` + `PUT /api/album/photos/{id}` |
| 头像 | 两人自选图片 | localStorage（`aion_avatar_yuri` / `aion_avatar_sean`），无仓库素材 |

连接状态显示规则（订阅线路）：`未登录` / `未安装` / `登录态存在` / `启动失败` / `可用`；API Key 线路显示线路名，永不标注「订阅」。

## 7. 导航技术约定

- 新页面共用 `static/mobile/theme.css`（变量源）+ `theme.js`（主题 boot 防闪烁）
- 聊天壳常驻 + 子页 iframe 浮层为聊天页既有机制；新首页直接链接独立页；Android 返回键由聊天壳 `handleNativeBack` 兼容
- 所有请求失败静默降级为空状态，不白屏；后端未接入的功能显示诚实的「未接入」空态，不放假数据
